# Exact certificates and saved evidence

Equal query sets (EQ) means that the specified relaxed model and exclusive reference admit the same complete declared queries. Strict inclusion (STRICT) means that at least one relaxed query has no exclusive realization. The [model scope](study_scope_and_model_assumptions.md) states the assumptions behind this comparison.

## Certification across horizons

The controlled design contains 468 predefined pairs, or 936 state slots. Of these, 176 are inapplicable under the design and 760 are applicable. The original protocol recorded 277 EQ, 331 STRICT and 152 unresolved assessments.

| Later route | Unchanged original inputs | Certificate requirement |
|---|---:|---|
| Lossless structural argument | 104 EQ | Saved native matrix guards must hold |
| Exact rational upper bounds | 45 EQ | Complete recorded sign and constraint family coverage; 3,417 exact bounds |
| Violating queries | 3 STRICT | Relaxed feasibility, query preservation and a native violation after reconstruction |

The cumulative result is 426 EQ and 334 STRICT. The same 468 pairs contain 82 certified EQ to STRICT changes, including the original 64. At 256 intervals, the final classification is eight EQ and 16 STRICT. The two equality routes have different applicability conditions.

## What the reader command checks

Run the combined command in the [quickstart](reviewer_quickstart.md). The device checks verify relaxed native feasibility, preserved queries, exclusive reconstruction and retained violations using saved vectors. Later certificates are checked by the retained arithmetic auditor through a path wrapper. These checks do not invoke a scientific solver or seek new cases.

Earlier logical equality outcomes and the 12 quantified domain decisions are preserved records. They are not newly replayed unsatisfiability proofs. Complete native feasibility, query preservation, objective agreement and selected request realizability remain separate conclusions.

## Network evidence

The Reliability Test System of the Grid Modernization Laboratory Consortium (RTS-GMLC) evidence contains three distinct objects.

| Object | Count | Supported conclusion |
|---|---:|---|
| Complete query set assessments | 8 at 7 distinct states | Four EQ and four STRICT for the retained network model |
| Original selected numerical requests | 8 | Native feasibility at the recorded numerical tolerances |
| Nearby exact feasible points | 24 | Exact native feasibility; none preserves the original complete query |

The network wrapper statically selects the reviewed non-solver functions of the unchanged independent verifier. It excludes the cvc5 import, the solver function and the original main routine. It checks saved set certificates, nonempty points and native rows. Separate request checks use numerical tolerances or exact fractions according to the object.
