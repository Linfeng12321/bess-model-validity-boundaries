# Paper source map

The [complete CSV map](main_sm_code_data_crosswalk.csv) connects 192 scientific objects to input files, programs, proofs and results. Each row retains its scientific definition, analysis unit, denominator and evidence role. Source paths are relative to this repository and carry SHA256 identities.

These objects overlap in scientific content; the total is a navigation count, not an experiment count. The [display index](figures_and_tables.md) offers a shorter route to figures and tables. The [code guide](code_provenance.md) groups programs by research function.

Figure 8 directional data and Figure 9 selected request data use separate directories and definitions. Equation S38 has a number in the Word and PDF reader although no LaTeX label was assigned; its expression binding remains in the map. No proposed future Introduction figure is represented as an included asset.

Source locators and parameter provenance remain available for the literature mappings. Publisher articles and optional native graph binaries are external. Figure S4 measurement access is described in the [external data guide](external_data_access.md); the reported window summaries are included.
