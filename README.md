# Validity Boundaries of Relaxed Battery Energy Storage System Models across Operating States

Research software and supporting materials for the study of complete query set validity, exclusive reconstruction and the realizability of storage dispatch requests.

**[Read the Supplementary Information](supplementary/Supplementary_Information.pdf)** · [Editable Word source](supplementary/Supplementary_Information.docx) · [Version 1.0.0](https://github.com/Linfeng12321/bess-model-validity-boundaries/releases/tag/v1.0.0)

## Quick start

With Python 3.12, run from the repository root. Only the Python standard library is needed:

```console
python -B scripts/verify_release.py --report-dir reports
```

The command verifies saved evidence and writes `reports/RELEASE_VERIFICATION.json` with a PASS result. It does not launch scientific solvers or generate new cases. See the [quickstart guide](docs/reviewer_quickstart.md) and [environment guide](ENVIRONMENT.md).

## Research overview

Charge and discharge exclusivity determines a unique reconstruction for each complete net power query and its retained variables. Checking this reconstruction against native operating constraints gives a necessary and sufficient criterion within the specified finite horizon affine model class. The study characterizes operating state dependence and distinguishes agreement in optimization values from realizability of complete scheduling queries.

## Research evidence

Equal query sets (EQ) and strict inclusion (STRICT) describe the relation between the exclusive and relaxed query sets.

| Research component | Evidence in this repository |
|---|---|
| Controlled operating states | 468 predefined pairs across 17 horizons from 4 to 256 intervals; 82 certified EQ to STRICT changes after cumulative certification |
| Horizon certification | 760 applicable assessments: 426 EQ and 334 STRICT |
| Literature device mappings | 34 instances from ten sources; 3,772 assessments: 113 EQ and 3,659 STRICT |
| Three bus dispatch | 26 state assessments; 16/26 economic and 17/26 service selections without an exclusive realization |
| 73 bus network model | Eight complete query set assessments: four EQ and four STRICT over seven distinct model states |

## Scope and reproducibility

The quickstart verifies saved arithmetic, native constraints and fixed summaries; it preserves earlier logical outcomes without repeating their solver searches. Selected numerical requests, nearby exact feasible points and complete query set certificates have different meanings. The [model scope](docs/study_scope_and_model_assumptions.md) and [certificate guide](docs/numerical_certificates.md) explain these distinctions. [Optional research reruns](docs/optional_full_research_rerun.md) use the retained implementations and recorded environments.
